# Create a PICO-8 game

1. Choose the main action, goal, feedback and relevant outcome or retry. Make the first actionable screen readable and the objective reachable.
2. Preserve existing work and constraints. Use the assets skill if authoring native sprites, maps or audio. Keep mechanics in update and rendering in draw.
3. Pass complete Lua to load_game for a new game or a rewrite. Inspect startup diagnostics, source budget and PNG before proceeding.
4. Read /extensions/pico8/skills/pico8-playtest/SKILL.md and exercise the main action and a representative outcome or retry.
