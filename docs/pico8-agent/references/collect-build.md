# Collect and build

Use for a gathering/construction request, or when repeated trips feel pointless.

**Loop:** find a source, collect, carry, deliver, see the construction change. Make the first delivery visibly useful before adding more materials.

**Choice:** a shared carrying limit, separated sources or an optional detour can change trip planning. Add a constraint only when it suits the requested mood. Different colors with identical locations and actions add bookkeeping, not a new choice. A brief relaxed loop can work without danger.

**Presentation:** keep terrain quieter than the character, usable sources and destination. Show collection progress, what is carried, and what the destination still needs. Distinguish material silhouettes at 128x128. Give collection, pickup and delivery distinct sound roles; reserve a channel for event feedback over music. Slot data does not establish audible quality.

**Check:** from empty inventory, collect each material, return, deposit, finish and restart. Inspect source-to-inventory type mapping and pickup range. Compare two plausible trips if route choice is intended. If they produce the same decisions, shorten repetition or adjust the constraint rather than adding another counter.
