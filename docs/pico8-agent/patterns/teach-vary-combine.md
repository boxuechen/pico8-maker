# Teach, vary, combine

These are transferable design proposals, not universal rules or copied implementations.

## Purpose

Introduce a mechanic in a safe context, then ask for a new application.

## Implementation

First show one rule with clear feedback. Change one spatial or timing variable. Combine only rules already demonstrated. Keep the input vocabulary stable while challenge changes.

## Tuning experiment

Use a three-beat sequence: forgiving first exposure, one variation, then a combination. Tune the first exposure separately from later difficulty.

## Failure modes

Changing enemy speed, range and controls at once makes failure hard to diagnose. Repeating the same room with more HP can add duration without new decisions.

## Verification

Ask a new player to describe the rule after the first encounter. Reuse an input trace to verify that the variation actually changes the challenge.
